# Letieri Silveira · Músico e Cantor

Site de agendamentos (HTML estático, sem dependências). Abra `index.html` no navegador ou publique com GitHub Pages
(Settings → Pages → Branch `master`, pasta `/`).

- Todos os botões abrem o WhatsApp `wa.me/5548996967255` com uma mensagem pronta.
- O formulário de agendamento monta a mensagem com nome, evento, data, local, duração, convidados e estilos.
- Para trocar o número, edite a constante `WHATSAPP` no final de `index.html`.
